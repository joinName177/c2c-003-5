# c2c-003 · 信息食谱调配师

Vue 3 + TypeScript + Vite 纯前端信息摄入管理工具。用户记录文章、视频、播客、社交媒体和书籍等信息消费，按深度知识、行业动态、技能提升、娱乐消遣、社交信息分类，通过营养金字塔、偏食检测、优化食谱与摄入报告管理信息饮食。数据保存在浏览器 `localStorage`。

## 分层

- 核心层 `src/core`：摄入记录、营养比例、偏食/缺失检测、餐盘评分与食谱建议
- 端口层 `src/ports`：信息食谱快照与提醒偏好的仓储接口、系统通知接口
- 适配器层 `src/adapters`：浏览器本地存储与 Notification API 实现
- 界面层 `src/ui`：Vue 页面与原生 CSS 视图

## 摄入提醒

提醒状态由当天数据实时派生（`src/core/reminder.ts`），不缓存完成度：

- **三个提醒时段，阈值随当日进度抬高**：午间 11:30–14:00（完成 < 30%）、傍晚 17:00–19:00（< 60%）、夜间 20:30–23:00（< 80%）。
- **参考最近一次记录时间**：刚记录过的一段时间内保持安静（午间 90 分钟，傍晚/夜间 180 分钟），安静期结束后仍不足才提醒。
- **当天已完成目标**（摄入 ≥ `dailyGoal`）任何时段都不再提醒。
- **提醒形式**：应用顶部横幅（可直接去记录），也可在顶栏开启浏览器系统通知；页面可见时只显示横幅，通知仅在标签页后台时推送，每个时段最多一次。
- **主动关闭**：点击「今天不再提醒」后，关闭状态与已通知时段按日期存入 localStorage，刷新或重开应用不会复活；跨天自动重置。
- **记录一次摄入**后完成度与提醒即时重算，新增/删除记录、修改时间推进都会重新评估。

提醒规则可通过 `npm run test:reminder` 校验。
